# funds-board

场外基金实时估算看板。应用用场内指数或 ETF 的盘中行情，估算已录入场外基金的当日盈亏。

## 功能

- 查询内置指数/ETF 知识库
- 录入场外基金、持有金额、关联指数/ETF、估算系数
- 录入并持久化持有收益、持有收益率
- 使用 SQLite 持久化基金持仓和指数知识库
- 根据基金最新净值展示实际当日收益，根据关联行情展示指数参考收益
- 每只基金按最新净值日期自动结算一次持有金额，避免重复刷新重复计入
- 支持按持有金额、当日涨跌金额、当日涨跌百分比、持有收益百分比排序
- 单独展示 QDII 基金的昨日实际收益与明日预估收益汇总
- 支持为单只基金同步加仓、减仓，并按原平台交易时间计算有效日
- 支持编辑、删除和手动刷新行情
- 用户只需要搜索名称或代码，系统内部自动选择行情源

## 持久化

SQLite 知识库文件位于：

```text
data/funds.sqlite
```

应用启动时会自动创建表，并写入一批常用指数/ETF 作为初始知识库。录入的基金持仓会保存到同一个 SQLite 文件中。

## 行情源

- `sh`、`sz`、`s_sh`、`s_sz` 标的走新浪财经实时行情
- `csi` 中证指数走中证指数官网最近交易日行情
- 页面只展示用户可理解的名称、代码和类型，内部 `provider_symbol` 不暴露给用户填写

## 说明

场外基金盘中没有真正实时净值，本应用会拆开展示两类收益：基金最新净值产出的实际当日收益，以及关联指数/ETF 涨跌幅产出的盘中参考收益。持有收益和持有收益率来自用户录入或截图初始化数据，并随持仓一起落到 SQLite。刷新持仓时，如果查询到某只基金更新了新的净值日期，系统会用该净值涨跌幅结算当前持有金额，并记录该净值日期；同一净值日期重复刷新不会再次结算。

加仓和减仓会记录为同步流水：原平台下午 3 点前交易按当日生效，下午 3 点后交易按次日生效。有效日对应基金净值结算完成后，本金变动只会应用一次，避免同一有效日重复刷新或错误计入当日涨跌。

```text
收益前金额 = 当前持有金额 / (1 + 涨跌幅)
今日估算盈亏 = 收益前金额 × 涨跌幅
```
